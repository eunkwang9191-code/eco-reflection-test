환경 성찰 검사 — 배포 가이드

1. 이 폴더 안 파일 전체를 GitHub 저장소의 루트에 업로드합니다.
2. GitHub 저장소 Settings > Pages > Build and deployment > Deploy from a branch 를 선택합니다.
3. Branch: main, Folder: /(root)를 선택하여 저장합니다.
4. 공개된 HTTPS 주소가 열리면 휴대폰에서 검사해 봅니다.
5. 공개 주소를 QR코드 생성기에 입력해 QR코드를 제작합니다.
6. Android: 브라우저 메뉴의 '홈 화면에 추가' 또는 '앱 설치'.
7. iOS: 공유 메뉴의 '홈 화면에 추가'.

주의
- QR은 공개 HTTPS URL이 나온 뒤 만들어야 합니다.
- 현재 버전은 학생의 전체 응답을 서버에 자동 저장하지 않습니다.
- 일관성 점수는 거짓말이나 정직성을 판별하지 않습니다.
- 사전/사후 개인별 기록·집계는 추후 서버 또는 Sheets 연동 작업이 필요합니다.
